Why these, and not the obvious alternatives

DecisionRejectedReason
Safe-to-spend as the herototal balance It is the only figure that answers the question the user has while standing at a shop counter.
Month ribboncategory donut Encodes spending rhythm, position in the month, and remaining runway at once. A donut shows category share, which the user already knows. Also ~31 draw calls, no library.
Ruled rowselevated cards Less overdraw per frame, and it matches the object the app replaces.
Light theme defaultdark default The target device is LCD, so dark saves no battery, and it is harder to read outdoors.
Custom numeric keypadsystem IME Removes 150–300 ms of keyboard inflation from the most frequent action in the app.
Income defaults to the yearmonth, for consistency A farming month showing ৳0 is alarming and meaningless. The year is the honest unit for this income.
Fixed tweens, 80–200 msM3 Expressive springs Spring settle tails are variable-length; on a Cortex-A53 that is where frames drop.
